Non-destructive by design

Private temporary uploadThe uploaded file receives a random server-side name and is removed after processing.
Current-state contextRelevant values are supplied to the planner so relative instructions can start from the actual preset.
Minimal change planA narrow request should produce a narrow list of explicit changes.
New downloadable copyYour original remains untouched. The generated filename follows the Audio Prompters timestamp convention.
Sample replacement and factory asset selection are not treated as ordinary numeric parameter edits. They require verified AudioSampleObject serialization and rights checks.

Reliable capture protocol

Save the baselineUse one Pigments version, one preset and one engine mode.
Move only one controlDo not play notes, randomize, switch tabs or alter another parameter.
Save as a new presetKeep the baseline unchanged and give the second save a clear suffix.
Compare hereOne changed serialized ID is ideal. Several changes may indicate dependent state or metadata noise.
