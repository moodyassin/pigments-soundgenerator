# Notice

Audio Prompters — Pigments Preset Lab includes code and research derived in part from the MIT-licensed project **Pigment Patch Generator** by Chanchal Kumar Ghosh (2026).

Retained or adapted concepts include:

- the initial Pigments preset-generation proof of concept;
- a serialized Pigments 7 default preset template used for development;
- the conservative stored-ZIP approach used to produce `.pgtx` archives;
- initial Pigments parameter research.

Major additions in this project include:

- server-side OpenAI Responses API integration;
- strict JSON-schema-constrained preset planning;
- a deterministic parameter compiler and validator;
- generation and non-destructive modification workflows;
- inspection and controlled before/after preset comparison;
- preservation of unspecified parameters, metadata, inner archive paths, and safe archive assets;
- `set`, `add`, `multiply`, and `toggle` operations;
- the user-maintained Pigments 7 Sound Design Master Database and a read-only import pipeline;
- a confidence-rated UI-to-serialization mapping overlay;
- compact runtime indexes for 125 documented controls and 3,525 observed internal IDs;
- 152 generated conservative compiler specifications;
- database integrity and reproducibility auditing;
- browser UI, security boundaries, tests, deployment documentation, and cross-platform packaging;
- an original Audio Prompters user-bank image replacing the inherited Arturia-style image asset.
